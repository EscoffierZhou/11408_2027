## 1. 核心方法论 (Methodology)

### 1.1 全景复杂度速查 (Master Complexity Table)

| 数据结构 (Data Structure) | 随机访问 (Access) | 查找 (Search) | 插入 (Insertion) | 删除 (Deletion) | 空间 (Space) | 备注 (Note) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **数组 (Array)** | $O(1)$ | $O(n)$ | $O(n)$ | $O(n)$ | $O(n)$ | 缓存友好，最紧凑 |
| **链表 (LinkedList)** | $O(n)$ | $O(n)$ | $O(1)$* | $O(1)$* | $O(n)$ | *需已知前驱节点指针 |
| **二叉搜索树 (BST)** | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | $O(n)$ | 最坏退化为链表 $O(n)$ |
| **平衡树 (AVL/RB)** | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | $O(n)$ | 此时 $O(\log n)$ 是稳定保证 |
| **哈希表 (Hash Table)** | N/A | $O(1)$ | $O(1)$ | $O(1)$ | $O(n)$ | 最坏 $O(n)$ (冲突) |
| **堆 (Heap/PQ)** | $O(1)$ (Top) | $O(n)$ | $O(\log n)$ | $O(\log n)$ | $O(n)$ | 只能高效操作Top |

### 1.2 空间换时间 (Time-Space Trade-off)
- **Hash Map**: 用 $O(n)$ 空间换取 $O(1)$ 查找（如 Two Sum）。
- **Pre-computation (前缀和)**: 用 $O(n)$ 空间换取 $O(1)$ 区间和查询。

## 2. ADT 核心体系 & 代码骨架 (Core ADTs & Templates)

### 2.1 线性结构 (Linear)

#### **1. 线性表 (List)**
*   **实现**: `vector` (C++), `ArrayList` (Java) vs `list`/`LinkedList`
*   **代码骨架: 哨兵位 (Dummy Node)**
    > **Why?** 统一头部和中间的插入/删除逻辑，避免 `head == null` 的边界判断。
    ```cpp
    ListNode* dummy = new ListNode(0);
    dummy->next = head;
    ListNode* cur = dummy; //此后操作 cur->next 即可
    return dummy->next;
    ```
*   **408/面试考点**:
    *   **断链**: 插入/删除时指针修改顺序（先连后断）。
    *   **边界**: 空表、表长为1、删除尾节点。

#### **2. 栈 & 队列 (Stack / Queue)**
*   **代码骨架: 单调栈 (Monotonic Stack)**
    > **Target**: 找左/右边第一个比自己大/小的元素 (Next Greater Element)。
    ```cpp
    stack<int> st;
    for (int i = 0; i < nums.size(); i++) {
        // 保持单调递增栈 (找右边第一个更小的)
        while (!st.empty() && nums[st.top()] > nums[i]) {
            int topIndex = st.top(); st.pop();
            // nums[i] 就是 nums[topIndex] 右边第一个比它小的
        }
        st.push(i);
    }
    ```
*   **核心应用**: 接雨水、最大矩形面积。

#### **3. 双端队列 (Deque)**
*   **代码骨架: 滑动窗口最大值**
    > **思路**: 队列内存放下标，保持队列内元素对应的数值是单调递减的。
    ```cpp
    deque<int> dq; // 存下标
    for (int i = 0; i < n; i++) {
        // 1. 队头过期 (超出窗口范围 k)
        if (!dq.empty() && dq.front() == i - k) dq.pop_front();
        // 2. 维护单调性 (新来的比你大, 你还没出队就没用了)
        while (!dq.empty() && nums[dq.back()] < nums[i]) dq.pop_back();
        dq.push_back(i);
        // 3. 取值 (队头永远是最大值)
        if (i >= k - 1) res.push_back(nums[dq.front()]);
    }
    ```

### 2.2 树形结构 (Tree)

#### **4. 二叉树 (Binary Tree)**
*   **递归思维**: **Base Case** -> **Logic** -> **Recursion**.
    ```cpp
    void dfs(TreeNode* root) {
        if (!root) return; // Base Case
        // Logic (Pre-order)
        dfs(root->left);
        dfs(root->right);
    }
    ```
*   **代码骨架: 层序遍历 (Level Order / BFS)**
    > **Target**: 按层打印、求最大深度、最小深度。
    ```cpp
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int size = q.size(); // 锁住当前层的数量
        for (int i = 0; i < size; i++) { // 遍历当前层
            TreeNode* cur = q.front(); q.pop();
            if (cur->left) q.push(cur->left);
            if (cur->right) q.push(cur->right);
        }
        level++; // 层数+1
    }
    ```
*   **408 考点**:
    *   完全二叉树的性质: $i$ 的左子 $2i$，双亲 $\lfloor i/2 \rfloor$。
    *   树高与节点数关系: $h = \lfloor \log_2 n \rfloor + 1$.

#### **5. 堆 (Heap)**
*   **操作复杂度**: `push` ($O(\log n)$), `pop` ($O(\log n)$), `top` ($O(1)$).
*   **应用**: Top K 问题 (用小顶堆维护最大的 K 个 -> 堆顶就是第 K 大)。
*   **C++ 陷阱**: `priority_queue` 默认是大顶堆 (`less` 比较器)，求第 K 大用小顶堆需 `greater`。

#### **6. 并查集 (Union-Find)**
*   **代码骨架: 路径压缩 + 按秩合并**
    ```cpp
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]); // 路径压缩
        return parent[x];
    }
    void unite(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX != rootY) parent[rootX] = rootY;
    }
    ```
*   **应用**: 连通分量个数、判断图中是否有环 (无向图)。

### 2.3 图算法 (Graph)

#### **7. 最短路径 (Shortest Path)**
*   **Dijkstra (单源, 无负权)**
    *   **核心**: 贪心 + 优先队列 (Min-Heap)。
    *   **复杂度**: $O(E \log V)$。
    *   **Code Skeleton**:
        ```cpp
        priority_queue<PII, vector<PII>, greater<PII>> pq;
        dist[start] = 0; pq.push({0, start});
        while (!pq.empty()) {
            auto [d, u] = pq.top(); pq.pop();
            if (d > dist[u]) continue; // 懒删除 (已有更短路径)
            for (auto& edge : adj[u]) {
                if (dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    pq.push({dist[v], v});
                }
            }
        }
        ```
*   **Floyd (多源)**: 动态规划，三层循环 `k, i, j`，复杂度 $O(V^3)$。

#### **8. 拓扑排序 (Topological Sort)**
*   **核心**: 入度表 (In-Degree) + 队列。
*   **步骤**:
    1.  统计所有点入度。
    2.  入度为 0 的入队。
    3.  BFS 拆边，减少邻居入度，减为 0 继续入队。
*   **应用**: 课程表依赖、构建系统变异顺序。

## 3. 必背基础算法 (Must-Memorize Algorithms)

### 3.1 排序 (Sorting)
**快速排序 (Quick Sort)**
*   **逻辑**: Partition (双指针)。
*   **复杂度**: 平均 $O(n \log n)$，最坏 $O(n^2)$ (有序数组需随机化 Pivot)。
*   **不稳定**。

**归并排序 (Merge Sort)**
*   **逻辑**: 分治 (Divide & Conquer) + 合并有序数组。
*   **复杂度**: 稳定 $O(n \log n)$。
*   **空间**: $O(n)$ (Temp 数组)。

**堆排序 (Heap Sort)**
*   **逻辑**: 建堆 $O(n)$ + 交换下沉 $O(n \log n)$。
*   **不稳定**。

### 3.2 二分查找 (Binary Search)
**代码骨架: 闭区间 `[left, right]`**
```cpp
int left = 0, right = n - 1;
while (left <= right) { // 注意 <=
    int mid = left + (right - left) / 2; // 防溢出
    if (nums[mid] == target) return mid;
    else if (nums[mid] < target) left = mid + 1;
    else right = mid - 1;
}
return -1;
```

**变种**: 寻找左边界 (Lower Bound) / 右边界 (Upper Bound)。
