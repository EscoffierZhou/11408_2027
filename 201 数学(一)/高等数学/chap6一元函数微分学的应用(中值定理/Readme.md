# chap6 一元函数微分学的应用(中值定理/微分等式/微分不等式)

## 1. 五大微分中值定理体系

#### 1. 费马引理 (Fermat):
设 $f(x)$ 在 $x_0$ 处可导并取得极值, 则必有 $f'(x_0) = 0$.

#### 2. 罗尔中值定理 (Rolle):
设 $f(x)$ 满足:
1. 在闭区间 $[a,b]$ 上连续;
2. 在开区间 $(a,b)$ 内可导;
3. 端点值相等 $f(a) = f(b)$;
则在 $(a,b)$ 内至少存在一点 $\xi \in (a,b)$, 使得 $f'(\xi) = 0$.

#### 3. 拉格朗日中值定理 (Lagrange):
设 $f(x)$ 满足在 $[a,b]$ 连续, 在 $(a,b)$ 可导, 则至少存在一点 $\xi \in (a,b)$, 使得:
$$f(b) - f(a) = f'(\xi)(b - a) \iff \frac{f(b) - f(a)}{b - a} = f'(\xi)$$
- 有限增量形式: $f(x_0 + \Delta x) - f(x_0) = f'(x_0 + \theta \Delta x)\Delta x \quad (0 < \theta < 1)$

#### 4. 柯西中值定理 (Cauchy):
设 $f(x), g(x)$ 在 $[a,b]$ 连续, 在 $(a,b)$ 可导, 且 $\forall x \in (a,b), g'(x) \neq 0$, 则至少存在一点 $\xi \in (a,b)$, 使得:
$$\frac{f(b) - f(a)}{g(b) - g(a)} = \frac{f'(\xi)}{g'(\xi)}$$

#### 5. 泰勒中值定理 (Taylor):
设 $f(x)$ 在包含 $x_0$ 的区间内 $n+1$ 阶可导, 对区间内任一点 $x$, 有:
$$f(x) = f(x_0) + f'(x_0)(x-x_0) + \frac{f''(x_0)}{2!}(x-x_0)^2 + \dots + \frac{f^{(n)}(x_0)}{n!}(x-x_0)^n + R_n(x)$$
- **拉格朗日余项:** $R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1} \quad (\xi \text{ 介于 } x_0 \text{ 与 } x \text{ 之间})$
- **皮亚诺余项:** $R_n(x) = o((x-x_0)^n) \quad (x \to x_0)$

## 2. 辅助函数构造法全谱 (微分等式证明核心)

| 目标待证结论形式 | 微分方程逆推特征 | 构造辅助函数 $\varphi(x)$ |
| :--- | :--- | :--- |
| $f'(\xi) + k f(\xi) = 0$ | $y' + ky = 0 \implies (ye^{kx})' = 0$ | $\varphi(x) = f(x)e^{kx}$ |
| $f'(\xi) + g'(\xi)f(\xi) = 0$ | $y' + g'y = 0 \implies (ye^{g(x)})' = 0$ | $\varphi(x) = f(x)e^{g(x)}$ |
| $\xi f'(\xi) + n f(\xi) = 0$ | $x y' + ny = 0 \implies (x^n y)' = 0$ | $\varphi(x) = x^n f(x)$ |
| $\xi f'(\xi) - f(\xi) = 0$ | $\frac{x y' - y}{x^2} = 0$ | $\varphi(x) = \frac{f(x)}{x}$ |
| $f'(\xi)g(\xi) + f(\xi)g'(\xi) = 0$ | $(uv)' = 0$ | $\varphi(x) = f(x)g(x)$ |
| $f'(\xi)g(\xi) - f(\xi)g'(\xi) = 0$ | $\left(\frac{u}{v}\right)' = 0$ | $\varphi(x) = \frac{f(x)}{g(x)}$ |
| $f''(\xi) + k f'(\xi) = 0$ | $(y'e^{kx})' = 0$ | $\varphi(x) = f'(x)e^{kx}$ |
| $f''(\xi) + f(\xi) = 0$ | 乘 $2f'(x) \implies (f'^2 + f^2)' = 0$ | $\varphi(x) = [f'(x)]^2 + [f(x)]^2$ |

## 3. 双中值与多中值定理证明技巧

#### 1. 双中值不相等的两种常见情形:
1. **区间拆分法 (中点分割):** 设 $c = \frac{a+b}{2}$, 在 $[a, c]$ 与 $[c, b]$ 上分别应用拉格朗日中值定理, 得到 $\xi_1 \in (a,c), \xi_2 \in (c,b)$, 显然 $\xi_1 \neq \xi_2$.
2. **柯西中值与拉格朗日中值配合法:** 分子分母分别在不同区间应用中值定理.

## 4. 微分不等式证明策略大全

1. **单调性法 (最常用):**
   - 证明 $f(x) > g(x) \ (x > a)$: 构造辅助函数 $h(x) = f(x) - g(x)$, 验证 $h(a) \ge 0$, 求导证 $h'(x) > 0 \implies h(x)$ 单调递增 $\implies h(x) > h(a) \ge 0$.
2. **最大最小值法:**
   - 证明 $f(x) \ge 0$: 求 $f(x)$ 在区间上的绝对最小值 $m$, 若 $m \ge 0$, 则不等式恒成立.
3. **拉格朗日中值定理法:**
   - 出现 $f(b) - f(a)$ 结构时, 改写为 $f'(\xi)(b-a)$, 利用导数的上下界进行放缩.
4. **泰勒公式展开法:**
   - 涉及高阶导数或二次以上不等式时, 将函数在特定点展开至二阶带拉格朗日余项.
5. **凹凸性割线/切线不等式:**
   - 若 $f''(x) > 0$ (凹函数), 则切线在曲线下方: $f(x) \ge f(x_0) + f'(x_0)(x-x_0)$.

## 5. 方程实根的个数与隔离法

#### 1. 实根存在性:
- 零点定理: 连续且 $f(a)f(b) < 0 \implies \exists \xi \in (a,b), f(\xi) = 0$.
- 罗尔定理推论: 若 $F'(x) = f(x)$ 且 $F(a) = F(b)$, 则 $f(x) = 0$ 必有实根.

#### 2. 实根唯一性与最多根定理:
- 若 $f'(x) > 0$ (严格单调) $\implies f(x) = 0$ 至多有 1 个实根.
- **罗尔定理推论 (实根上界判据):** 若在区间 $I$ 上 $f^{(n)}(x) \neq 0$, 则方程 $f(x) = 0$ 在 $I$ 内至多有 $n$ 个实根.

## 6. 易错点与典型陷阱分析

1. **中值点开闭区间混淆:** 罗尔、拉格朗日、柯西中值点 $\xi$ 必须严格落在开区间 $(a,b)$ 内, 严禁取端点.
2. **两处中值点误设为同一符号:** 对同一函数在不同区间或对不同函数使用拉格朗日中值定理时, 必须使用不同的中值符号 $\xi_1 \neq \xi_2$.
3. **使用柯西中值定理时未验证分母导数非零:** 若 $g'(x)$ 在区间内有零点, 柯西中值定理失效.
