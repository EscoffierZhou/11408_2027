# chap7 一元函数微分学的应用(物理应用和经济应用)

## 1. 相关变化率问题

#### 1. 定义与本质:
设两个变量 $x$ 和 $y$ 均是时间 $t$ 的可导函数 $x = x(t), y = y(t)$, 且它们之间满足某种几何或物理关联方程 $F(x, y) = 0$.
- 变化率: $\frac{dx}{dt}$ 与 $\frac{dy}{dt}$ 称为相关变化率.
- 求解核心: 对关联方程两边关于时间 $t$ 求全导数, 建立 $\frac{dx}{dt}$ 与 $\frac{dy}{dt}$ 的代数方程, 代入已知量求未知变化率.

#### 2. 常见相关变化率经典模型:
1. **梯子下滑模型:** 梯长 $L$, 脚距墙 $x$, 顶距地 $y$, 满足 $x^2(t) + y^2(t) = L^2 \implies 2x\frac{dx}{dt} + 2y\frac{dy}{dt} = 0$.
2. **注水锥形水斗模型:** 圆锥容器高 $H$, 底半径 $R$, 水深 $h(t)$, 体积 $V(t) = \frac{1}{3}\pi r^2 h = \frac{\pi R^2}{3H^2}h^3 \implies \frac{dV}{dt} = \frac{\pi R^2}{H^2}h^2\frac{dh}{dt}$.
3. **人影移动模型:** 设路灯高 $H$, 人高 $h$, 人距灯下距离 $x(t)$, 影长 $s(t)$, 由相似三角形 $\frac{s}{s+x} = \frac{h}{H} \implies s(t) = \frac{h}{H-h}x(t) \implies \frac{ds}{dt} = \frac{h}{H-h}\frac{dx}{dt}$.

## 2. 运动学物理应用

1. **瞬时速度与加速度:**
   - 运动方程: $s = s(t)$
   - 瞬时速度: $v(t) = \frac{ds}{dt} = s'(t)$
   - 瞬时加速度: $a(t) = \frac{dv}{dt} = \frac{d^2s}{dt^2} = s''(t)$
2. **变力加速度与微分关系:**
   - 牛顿第二定律: $F = ma = m\frac{dv}{dt} = mv\frac{dv}{ds}$

## 3. 经济学应用核心概念

#### 1. 常用经济函数体系:
1. **总成本函数 $C(Q)$ 与平均成本 $AC(Q)$:**
   - $C(Q) = C_0 + C_1(Q)$ ($C_0$ 为固定成本, $C_1(Q)$ 为可变成本)
   - 平均成本: $AC(Q) = \frac{C(Q)}{Q}$
   - **边际成本:** $MC(Q) = C'(Q) = \lim_{\Delta Q \to 0}\frac{\Delta C}{\Delta Q}$
2. **需求函数 $Q = f(P)$ 与反需求函数 $P = P(Q)$:**
   - 价格 $P$, 需求量 $Q$ (通常需求量随价格单调递减, $f'(P) < 0$)
3. **总收益函数 $R(Q)$ 与总利润函数 $L(Q)$:**
   - 总收益: $R(Q) = P \cdot Q = Q \cdot P(Q)$
   - 边际收益: $MR(Q) = R'(Q)$
   - 总利润: $L(Q) = R(Q) - C(Q)$
   - **利润最大化原则:** $L'(Q) = 0 \implies MR(Q) = MC(Q)$ (边际收益等于边际成本时利润最大)

#### 2. 需求价格弹性 (Elasticity of Demand):
- **定义:** 需求量变动百分比对价格变动百分比的极限响应程度:
  $$\eta = \lim_{\Delta P \to 0}\frac{\Delta Q / Q}{\Delta P / P} = \frac{P}{Q}\frac{dQ}{dP}$$
  *(考研数学中通常定义弹性系数为正值 $\eta = -\frac{P}{Q}\frac{dQ}{dP}$ 或带负号根据题目上下文而定)*
- **弹性与收益的关系:**
  $$\frac{dR}{dP} = \frac{d(P \cdot Q)}{dP} = Q + P\frac{dQ}{dP} = Q\left(1 + \frac{P}{Q}\frac{dQ}{dP}\right) = Q(1 - \eta)$$
  1. 若 $\eta > 1$ (富有弹性): $\frac{dR}{dP} < 0 \implies$ 降价可使总收益增加 (薄利多销)
  2. 若 $\eta < 1$ (缺乏弹性): $\frac{dR}{dP} > 0 \implies$ 涨价可使总收益增加
  3. 若 $\eta = 1$ (单位弹性): $\frac{dR}{dP} = 0 \implies$ 收益达到最大值

## 4. 优化建模与最值应用题求解规范

#### 1. 建模通用解题四步法:
1. **选定自变量与目标函数:** 设立合适自变量 $x$, 建立目标函数 $y = f(x)$ 并明确实际意义下的物理/几何定义域 $x \in [a,b]$ 或 $(a,b)$.
2. **求驻点与不可导点:** 求导令 $f'(x) = 0$, 找出区间内的唯一驻点 $x_0$.
3. **极值判定与最值确立:**
   - 若实际问题必然存在最值, 且在开区间内只有一个驻点, 则该驻点处的极值必为**全局绝对最值**.
4. **作答与检验单位:** 检验结果是否符合实际物理意义.

## 5. 易错点与典型陷阱总结

1. **相关变化率求导遗漏时间导数 $\frac{dt}{dt}$ 链式项:** 对 $x^2$ 关于 $t$ 求导必须为 $2x\frac{dx}{dt}$, 误写为 $2x$.
2. **需求价格弹性正负号混乱:** 务必看清题干中弹性的定义是带负号使其为正, 还是保留负值.
3. **最值问题忽略区间端点:** 若实际意义包含闭区间端点, 必须对比端点值与驻点函数值.
