# chap26 附录: 古鲁金定理及其运用

## 1. 古鲁金两大定理体系

#### 1. 古鲁金第一定理 (旋转曲面表面积定理):
一条平面曲线弧 $L$ 绕与它共面且不相交的轴旋转一周所得旋转曲面的面积 $S$, 等于该曲线的弧长 $L$ 与其形心 $(\bar{x}, \bar{y})$ 绕旋转轴旋转所形成的圆周长 $2\pi \bar{d}$ 的乘积:
$$S = 2\pi \bar{d} \cdot L$$
*(其中 $\bar{d}$ 为曲线弧形心到旋转轴的垂直距离)*

#### 2. 古鲁金第二定理 (旋转体体积定理):
一块平面闭区域 $D$ 绕与它共面且不相交的轴旋转一周所得旋转体的体积 $V$, 等于该区域的面积 $A$ 与其形心 $(\bar{x}, \bar{y})$ 绕旋转轴旋转所形成的圆周长 $2\pi \bar{d}$ 的乘积:
$$V = 2\pi \bar{d} \cdot A$$
*(其中 $\bar{d}$ 为区域形心到旋转轴的垂直距离)*

## 2. 古鲁金定理双向实战神技

1. **正向秒求旋转体体积与表面积:**
   - 圆环体 (Torus): 圆 $(x-a)^2 + y^2 \le R^2 \ (a > R)$ 绕 $y$ 轴旋转:
     - 形心距轴 $\bar{d} = a$, 面积 $A = \pi R^2$, 周长 $L = 2\pi R$
     - **体积 $V = 2\pi a \cdot \pi R^2 = 2\pi^2 a R^2$**
     - **表面积 $S = 2\pi a \cdot 2\pi R = 4\pi^2 a R$**
2. **反向秒求复杂图形形心坐标:**
   - 已知半圆域 $x^2+y^2 \le R^2 \ (y \ge 0)$ 绕 $x$ 轴旋转得球体, 体积 $V = \frac{4}{3}\pi R^3$, 面积 $A = \frac{\pi R^2}{2}$:
     $$\bar{y} = \frac{V}{2\pi A} = \frac{\frac{4}{3}\pi R^3}{2\pi \cdot \frac{\pi R^2}{2}} = \frac{4R}{3\pi}$$
