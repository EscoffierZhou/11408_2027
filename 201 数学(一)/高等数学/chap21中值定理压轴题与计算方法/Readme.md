## 1. 辅助函数构造法全景大纲 (微分方程逆推法)

| 待证结论形式 | 逆推微分方程特征 | 构造辅助函数 $\varphi(x)$ |
| :--- | :--- | :--- |
| $f'(\xi) + k f(\xi) = 0$ | $(ye^{kx})' = 0$ | $\varphi(x) = f(x)e^{kx}$ |
| $f'(\xi) + g'(\xi)f(\xi) = 0$ | $(ye^{g(x)})' = 0$ | $\varphi(x) = f(x)e^{g(x)}$ |
| $\xi f'(\xi) + n f(\xi) = 0$ | $(x^n y)' = 0$ | $\varphi(x) = x^n f(x)$ |
| $\xi f'(\xi) - f(\xi) = 0$ | $\left(\frac{y}{x}\right)' = 0$ | $\varphi(x) = \frac{f(x)}{x}$ |
| $f'(\xi)g(\xi) + f(\xi)g'(\xi) = 0$ | $(fg)' = 0$ | $\varphi(x) = f(x)g(x)$ |
| $f'(\xi)g(\xi) - f(\xi)g'(\xi) = 0$ | $\left(\frac{f}{g}\right)' = 0$ | $\varphi(x) = \frac{f(x)}{g(x)}$ |
| $f''(\xi) + k f'(\xi) = 0$ | $(y'e^{kx})' = 0$ | $\varphi(x) = f'(x)e^{kx}$ |
| $f''(\xi) + \omega^2 f(\xi) = 0$ | $(f'^2 + \omega^2 f^2)' = 0$ | $\varphi(x) = [f'(x)]^2 + \omega^2 [f(x)]^2$ |

## 2. 双中值证明分类与破局模型

#### 1. 形式一: $\xi \neq \eta$ 在不同子区间 (区间分割法):
- **方法:** 选取中点 $c = \frac{a+b}{2}$, 在 $[a, c]$ 与 $[c, b]$ 上分别应用拉格朗日中值定理, 得到 $\xi \in (a,c), \eta \in (c,b)$, 天然满足 $\xi \neq \eta$.

#### 2. 形式二: 柯西中值与拉格朗日中值联立:
- **方法:** 对两个不同函数或同一函数在不同表达式下分别应用柯西与拉格朗日中值定理.

## 3. 泰勒公式证明中值压轴题的三大标准套路

#### 1. 展开点选取原则:
- 题干含区间中点信息 $\implies$ 在**中点展开**到两端点 $a$ 与 $b$.
- 题干含端点导数信息 $\implies$ 在**端点展开**.
- 题干含驻点或极值点 $\implies$ 在**驻点展开**消去一阶导数项.

#### 2. 双向展开加减法:
$$f(x_0+h) = f(x_0) + f'(x_0)h + \frac{f''(x_0)}{2}h^2 + \frac{f'''(\xi_1)}{6}h^3$$
$$f(x_0-h) = f(x_0) - f'(x_0)h + \frac{f''(x_0)}{2}h^2 - \frac{f'''(\xi_2)}{6}h^3$$
两式相减消去偶次项, 两式相加消去奇次项.
