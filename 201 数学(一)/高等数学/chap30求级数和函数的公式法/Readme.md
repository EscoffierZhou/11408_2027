# chap30 附录: 求级数和函数的公式法

## 1. 幂级数求和函数的标准双通道

#### 1. 逐项微积分法 (先积后导 / 先导后积):
1. **带系数 $n$ 型 (先积分后求导):**
   求 $S(x) = \sum_{n=1}^\infty n x^n$:
   - 提 $x$: $S(x) = x \sum_{n=1}^\infty n x^{n-1}$
   - 积分消系数: 令 $g(x) = \sum_{n=1}^\infty n x^{n-1} \implies \int_0^x g(t)dt = \sum_{n=1}^\infty x^n = \frac{x}{1-x}$
   - 求导还原: $g(x) = \left(\frac{x}{1-x}\right)' = \frac{1}{(1-x)^2} \implies S(x) = \frac{x}{(1-x)^2} \ (|x| < 1)$
2. **带分母 $n$ 型 (先求导后积分):**
   求 $S(x) = \sum_{n=1}^\infty \frac{x^n}{n}$:
   - 求导消分母: $S'(x) = \sum_{n=1}^\infty x^{n-1} = \frac{1}{1-x}$
   - 积分还原: $S(x) = \int_0^x \frac{1}{1-t}dt = -\ln(1-x) \ (x \in [-1, 1))$

## 2. 微分方程法求幂级数和函数

对于含有阶乘或复杂递推系数的幂级数 $S(x) = \sum a_n x^n$:
1. 求一阶与二阶导数 $S'(x), S''(x)$
2. 建立 $S(x)$ 满足的常系数线性微分方程 $S'(x) + P(x)S(x) = Q(x)$
3. 由初始条件 $S(0) = a_0$ 求解微分方程得到和函数封闭解析式.

## 3. 数项级数求和的阿贝尔第二定理

若幂级数 $\sum a_n x^n$ 在收敛区间端点 $x = R$ 处收敛, 则和函数在端点处左连续:
$$\sum_{n=0}^\infty a_n R^n = \lim_{x \to R^-} S(x)$$
