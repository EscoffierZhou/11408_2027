| 曲线名称 | 方程形式 | 围成面积 $S$ | 全周长弧长 $L$ | 绕 $x$ 轴旋转体体积 $V_x$ | 绕 $x$ 轴侧面积 $S_x$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **心形线** | $r = a(1 + \cos\theta)$ | $\frac{3}{2}\pi a^2$ | $8a$ | $\frac{8}{3}\pi a^3$ | $\frac{32}{5}\pi a^2$ |
| **摆线 (单拱)** | $\begin{cases} x = a(t - \sin t) \\ y = a(1 - \cos t) \end{cases}$ | $3\pi a^2$ | $8a$ | $5\pi^2 a^3$ | $\frac{64}{3}\pi a^2$ |
| **星形线** | $\begin{cases} x = a\cos^3 t \\ y = a\sin^3 t \end{cases}$ | $\frac{3}{8}\pi a^2$ | $6a$ | $\frac{32}{105}\pi a^3$ | $\frac{12}{5}\pi a^2$ |

| **阿基米德螺线** | $r = a\theta \ (0 \le \theta \le 2\pi)$ | $\frac{4}{3}\pi^3 a^2$ | $\pi a(2\pi\sqrt{1+4\pi^2}+\dots)$ | - | - |
