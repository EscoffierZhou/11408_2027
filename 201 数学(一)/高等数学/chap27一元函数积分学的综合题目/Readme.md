# chap27 附录: 一元函数积分学的综合题目

## 1. 考研数学(一) 高频综合大题模型

#### 1. 变上限积分函数与微分方程联立模型:
- **标准解题套路:**
  1. 初始条件代入 (令 $x=0$, 求得 $y(0)$ 或 $F(0)$)
  2. 对积分等式两边关于 $x$ 求导, 消除积分号, 转化为标准一阶/二阶微分方程
  3. 解微分方程得到原函数 $y(x)$, 进而讨论极值、拐点、单调区间及渐近线.

#### 2. 积分与极限、中值定理压轴综合模型:
- 涉及 $\lim_{x \to 0} \frac{\int_0^x f(t)dt}{x^k}$ 结构, 优先考虑洛必达法则结合变限积分求导, 或将 $f(t)$ 在 0 处泰勒展开后逐项积分.

## 2. 经典例题精析与复盘

- **例题:** 设连续函数 $f(x)$ 满足 $f(x) = x + 2\int_0^1 x t f(t)dt$, 求 $f(x)$.
  - *解:* 令常数 $A = \int_0^1 t f(t)dt$, 则 $f(x) = x + 2Ax = (1+2A)x$.
  - 代入常数定义式: $A = \int_0^1 t (1+2A)t dt = (1+2A)\int_0^1 t^2 dt = \frac{1+2A}{3} \implies 3A = 1+2A \implies A = 1$.
  - 故 $f(x) = 3x$.
